Multiple Ports Display

How should multiple listening ports be shown in the sidebar?

fullstack :3000 :5173 :5432
~/projects/myapp
⎇ main*

A: Inline list

All ports listed on one line, space-separated. Simple but can overflow if many ports.

fullstack :3000 +2
~/projects/myapp
⎇ main*
Tooltip/hover: :3000 :5173 :5432

B: Primary port + badge

Shows first port + "+N" badge. Full list on hover tooltip. Stays compact even with many ports.

fullstack
~/projects/myapp
⎇ main* :3000 :5173 :5432

C: Ports on git row (right-aligned)

Git branch left, all ports right on the same row. Uses horizontal space efficiently. Wraps naturally if many ports.
